Important Meta Policy Note: Instagram DMs via Official Graph API

Instagram DMs via the official Graph API require either that the user has previously messaged your business, OR that you use the Private Replies API (recipient: {"comment_id": "..."}) within 7 days of the user commenting on your post, with the instagram_manage_messages permission. While your Meta App is in Development Mode, automated replies and DMs work immediately for App Admins/Developers/Testers. To message any public Instagram user, submit your app for Meta App Review under App Review → Permissions and Features with a screen recording of this dashboard.
